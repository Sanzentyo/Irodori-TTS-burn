# Burn 0.22 stable migration review

Self-review of the dependency/API migration and local patches against base
`ad11d15c0aed1c6841f7bde8f23fa1b3bd45dc1f`, before committing directly to
the repository's default branch (`master`). No independent reviewer was used.
The scope includes root consumers, optional features, benchmark scripts,
the isolated Fusion experiment and differences from the pinned upstream
archives. Existing user edits to the August RF follow-up report are excluded.

## Findings and resolutions

1. **Handwritten shader language was rejected by AutoCompiler.** Stable CubeCL
   validates the source language against the selected compiler. On Vulkan the
   generated-code default is SPIR-V. AutoCompiler now selects WGSL for a kernel
   carrying WGSL source, keeping the compiler and language tag consistent for
   that pipeline. A fresh compiler is created per kernel; generated IR still
   uses the native compiler. The mixed WGSL-copy/generated-kernel capture test
   exercises both initial capture and subsequent input replacement/replay.
2. **Fusion feature unification replaced production dispatch.** The previous
   opt-in provider feature could no longer coexist with raw CubeTensor access.
   Its implementation and tests now live in a separate Cargo workspace with
   its own lockfile. The provider forwards the new relative-shape metadata
   contract. Host-specific reverse dependency trees confirm that normal root
   builds enable WGPU and do not enable the Fusion dispatch backend.
3. **Local kernel extension points moved.** CubeK's matmul traits now live
   under `multi_level` and the runtime parameter is erased. The post-cast,
   accumulator and paired/compressed writers were migrated together with
   their launchers. Runtime vector indices use dynamic extraction/insertion.
   The Intel variable-subgroup reduction and fixed-plane admission checks
   remain present. Tail lanes still participate in required barriers.
4. **New graph and timing APIs expose errors.** Replay and memory cleanup
   failures are propagated; absent timing results are errors. Captured input,
   output and owning model lifetimes remain tied to the existing owner.
   No new application unsafe boundary or leak was introduced. The upstream
   graph implementation replaces the prior local implementation.
5. **Checkpoint snapshot ownership changed.** Burn Store's deferred tensors
   require thread-safe readers. A shared mutex covers each seek/read pair;
   the file stays alive until the deferred reader is dropped. Native bytes
   use checked TensorData construction. Full MF parameter digests agree
   across versions, file formats and GPUs; the RF packed digest also agrees.
6. **Allocator scripts still used the removed preset.** The current tools and
   their four shell callers now use `adaptive`, including the sorted JSON
   assertion in the allocator campaign. Historical benchmark reports retain
   their original allocator names. No compatibility alias silently equates
   the old and new allocator algorithms.
7. **Test processes exited with outstanding GPU work.** The first rejected-mask
   test satisfied its expected panic, then crashed during native teardown.
   Its test helper now catches the panic, waits for device completion and
   resumes the original panic; other rejection cases use the same helper.
   Shape/metadata-only cases exposed by the continued suite also wait for
   completion. No numerical assertion or panic expectation was weakened.
8. **Intel FP16 is a remaining numerical limitation.** The RF waveform SNR
   falls from 43.960 to 33.610 dB against the fixed FP32 oracle in the final
   candidate. Restoring old WGSL choices in a private diagnostic cache did
   not fix the preliminary candidate; the final corrected policy was then
   independently tuned and remeasured. This is documented in the README and comparison.
   FP32 remains the default and all measured FP32 cases pass the existing
   gates. This migration does not claim unchanged Intel FP16 accuracy, and
   it adds no automatic portable/FP32 fallback to conceal the result.
9. **The new native backend defaulted masks to U8.** Handwritten WGSL softmax
   and plane attention require U32. The central device configuration now pins
   and verifies U32 alongside the explicit float/I32 policy; callers do not
   insert repeated conversions. New FP32 v7 / FP16 v8 namespaces invalidate
   candidate selections made while those routes were unavailable. Six mask
   and softmax GPU tests pass after this fix. Final inference is remeasured
   with the corrected policy; the earlier candidate is retained as evidence.
10. **Convolution bias was charged as a full accumulator matrix.** Stable
    CubeK validates accumulator-reader shared memory, but `SyncBiasLoading`
    stages only one row. A distinct `ColumnBias` contract carries that fact
    through the selector and budget check. Partial-output and weight-layout
    tests now launch within the actual memory budget and pass without raising
    device limits or bypassing validation.
11. **The k7 fan-out reader emitted an invalid workgroup pointer bitcast.**
    NVIDIA crashed while compiling that SPIR-V pipeline. `spirv-val` confirms
    that the generated pointer cast is invalid for the logical addressing
    model. Keeping the scalar shared allocation and its scalar tile coordinates
    together removes the cast; cooperative-matrix loads consume that view
    directly. The repack/halo/fan-out equivalence test passes after the fix,
    and the final emitted shader passes `spirv-val --target-env vulkan1.3`.

## Impact and evidence

The changed compute foundations reach the model, codec, custom kernels,
loading adapters, graph capture and every root binary. Both old/new resolved
Cargo metadata and reverse dependency trees are retained in the artifact
directory. Host feature trees are used for enabled-backend claims: the
unfiltered metadata graph also contains edges for other target platforms.
The dependency-free WGSLPack format remains optional and unchanged.

The [comparison](../benchmarks/burn-0.22-upgrade-2026-10-13.md) records all
eight inference cells, the repeated original baseline, 32 MF load processes,
RF compatibility and the rejected numerical-control experiments. Binary and
input hashes tie timing claims to those executables. The `final` inference
campaign includes the U32-mask policy and convolution contract repairs. The
loader campaign predates those repairs, which do not change parameter loading;
its exact executable hashes remain recorded separately.

Validation is a union of recorded runs, with failures repaired and rerun:

- All 685 ordinary workspace tests have passing results. The repeated library
  run covers all 676 library cases including 33 opt-in GPU/tokenizer cases;
  its caption-shape teardown was fixed, and its missing tokenizer environment
  variable was supplied for the focused rerun. The final 18-case repair suite
  passes on the rebuilt library. Numerical assertions were not weakened.
- Three targeted Intel GPU tests pass: softmax lane boundaries, partial-tile
  FP32/FP16 GEMM versus CPU, and tuned FP16 attention with strided inputs and
  fully masked rows.
- Both WGSLPack GPU integration tests pass on RTX; the borrowed descriptor and
  payload test also passes on Intel. The packed model test verifies that the
  exact-only loader omits duration parameters.
- Root `cargo clippy --workspace --all-targets --all-features -- -D warnings`
  passes. Minimal library feature configurations and the dependency-free
  WGSLPack reader compile separately from the all-features build.
- The independent Fusion experiment passes Clippy and all three tests,
  including its opt-in GPU provider test.
- WGSLPack's two doctests pass; the root's four existing ignored examples are
  still ignored. Root/experiment formatting and shell syntax checks pass.

Cargo refuses `nextest -p cubek-convolution` because the vendored dependency
is outside the workspace and needs dev-dependencies. Its standalone upstream
test suite is not claimed as tested; the parameterized launch contracts and
local numerical changes are exercised by the root GPU consumer tests above.

Only Linux Vulkan on RTX 5070 Ti Laptop and Intel ARL was executed. Metal,
DX12, other GPUs, the full five-length sweep, listening/MOS and recognition
accuracy are not certified by this upgrade campaign.
